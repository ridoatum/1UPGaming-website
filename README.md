## Setup

1. **Clone or download** this repository
2. Open `index.html` in a browser — no build step required
3. **Optional — RAWG API** for game cover images:
   - Sign up for a free key at [rawg.io/apidocs](https://rawg.io/apidocs)
   - Open `js/main.js` and replace `'YOUR_RAWG_API_KEY'` with your actual key
   - Without a key, the library still works using emoji placeholder cards
